# 디자인 가이드

pkpkdupr web의 화면을 바꾸거나 시안을 만들 때 따르는 결정이다. 색·버튼·경기 행·평점 표시·바텀시트·탭 머리·화면 이동 같은 규칙은 `apps/web/AGENTS.md`("현재 UX / 상태 관리 규칙"·"스타일링 규칙"·"디자인 규칙")에 있으므로 여기서 다시 쓰지 않는다. 이 문서는 그 밖의 확정된 결론과 다시 제안하지 않을 안을 모은다. 실제 값은 `apps/web/src/index.css`의 `@theme`가 기준이며 이 문서와 다르면 코드를 따른다.

## 작업 방식

- UI 변경은 구현 전에 시안부터 낸다. 디자인 캔버스에 지금 화면과 안 여러 개를 나란히 두고 고르게 한다. 시안을 만드는 순서는 `.claude/skills/design-canvas/SKILL.md`를 따른다.
- 확정 지시 전에는 코드·이슈 작업을 시작하지 않는다. 확정되지 않은 안을 기존 시안 화면에 먼저 반영하지 않는다.
- 시안은 기존 컴포넌트(`apps/web/src/components/ui/`와 해당 화면 컴포넌트)를 옮겨 그린다. 비슷한 모양을 새로 그리지 않는다.
- 아이콘·배지처럼 작게 보이는 것은 그림만 늘어놓지 말고 실제 크기로 렌더링한 화면 안에서 비교하게 한다.
- "B안으로"처럼 여러 아트보드에 걸칠 수 있는 답은 어느 아트보드인지 확인한다(예: "B안"과 "B안 + 추가 요소"가 함께 있을 때).
- 확정된 결정은 이 문서나 `apps/web/AGENTS.md`에 반영한다. 개인 메모나 캔버스에만 남기지 않는다.

시안의 기준은 지금 앱 화면과 코드다. 예전 디자인 캔버스는 참고 자료일 뿐이고(비공개라 소유자에게 공유를 받아야 열린다), 확정된 내용은 모두 이 문서와 `AGENTS.md`에 있다.

## 전체 원칙

- 검정 바탕 버튼과 코랄 계열 색은 쓰지 않는다.
- 하단 바는 아이폰풍으로 떠 있는 유리 알약 탭바와 원형 + 버튼이다. 없애지 않고, 스크롤해도 모양이 바뀌지 않는다.
- 바텀시트 위에 바텀시트를 겹쳐 쌓지 않는다.
- 코트 평면도 그림은 쓰지 않는다(기록에서 선수 자리는 중요하지 않다). 진행 중 경기의 옆에서 본 랠리 그림(바닥 선·네트·패들)은 쓴다.
- 코트 번호처럼 빈 코트도 표시하지 않는다. 추천한 코트에서 실제로 경기한다는 보장이 없다.
- 섹션 제목 위 여백은 앞 요소에서 제목 줄까지 20px, 제목 줄에서 내용까지 10px로 모든 화면이 같다(같은 섹션 안 카드 사이도 10px). 섹션 제목이 붙는 묶음은 공용 `Section`(`apps/web/src/components/ui/Section.tsx`)으로만 만든다. 화면 머리·컨트롤 바로 아래 첫 제목은 위 여백을 더하지 않고, 제목 없는 카드 사이 간격은 화면대로 둔다.
- 섹션 제목 옆에 목록 개수(" · N")를 붙이지 않는다. 개수 자체가 정보인 경우(홈 "추천 매칭 · 대기 N명")만 예외다.
- 화면 문구는 '선수' 대신 '플레이어', '고르기' 대신 '선택'을 쓴다. 부연 안내 문구는 넣지 않고 오류 안내만 둔다.

## 화면별 결정

### 경기 기록·수정

- 입력과 수정은 제목·버튼 문구·완료 화면까지 같은 UI다. 수정은 값이 채워져 있다는 점만 다르다.
- 저장은 길게 눌러 확정(`HoldToConfirmButton`)이다. 한 번 탭으로 바꾸지 않는다.
- 점수는 두 팀 모두 고르고 이긴 팀은 점수 비교로 정한다. 이긴 팀 점수를 11점으로 고정하거나 자동으로 채우지 않는다(듀스·대회 룰). 점수 선택은 가로 스크롤이다.
- 듀스 관련 판정·문구는 동호회 15점 캡(`docs/product.md`)을 전제로 하지만, 점수 입력 UI에는 상한을 두지 않는다.
- 세트·게임 수 개념(2선승 등)을 UI에 다시 넣지 않는다(단판만, `docs/product.md`).
- 복식/단식 선택 UI 없이 양 팀 1명씩이면 단식이다. 선수를 뺄 때 다른 선수를 자동으로 옮기지 않는다.
- 시작 시각 입력, QR(멤버 QR 추가·내 QR), 시트 바깥 X 버튼, 점수 단계 위쪽 뒤로·X 버튼, 버튼의 남은 시간 표시, 별도 빼기·선택 취소 버튼은 없다. 입력 중에 시트를 닫아도 확인 없이 닫는다.
- 플레이어 목록에서 세션 참여자를 앞에 두되 섹션·구분선으로 나누지 않는다.
- '한 판 더'는 '같은 멤버로 한 판 더'로 쓰고, 누르면 바로 진행 중 경기를 만든다. 기록 완료의 "한 판 더"/"닫기"는 같은 너비 두 칸이고 닫기가 주 버튼이다.
- 기록 완료 머리는 점수판 위 가운데 13px 한 줄 "✓ 기록했어요 · <세션 이름>"이다. 경기 상세 맨 위 "날짜 · 세션" 줄과 같은 자리·모양이고, 아래 내용이 더 보이도록 높이를 낮춘 것이다. 평점 변화 칸에는 제목을 달지 않는다.
- 기록 완료와 경기 상세는 이 경기로 참가자 전원이 받은 업적을 보인다(남의 경기를 대신 기록해도 보인다). 줄 모양은 같다(`MatchAchievementRow`): 왼쪽 배지 → 업적 이름·조건 → 오른쪽 끝에 받은 회원 아바타 위·아이디 아래. 나를 따로 강조하지 않고 '새 업적' 같은 머리 문구는 붙이지 않는다. 누르면 그 회원의 업적 상세.
  - 기록 완료는 점수판 아래 연한 파랑 띠, 경기 상세는 평점 변화 아래 '이 경기로 받은 업적' 흰 카드다. 업적이 없으면 둘 다 보이지 않는다.
  - 화면 전체 축하 연출과 확인 처리는 내 업적만이다.

### 홈

- 진행 중 세션도 다음 세션과 같은 블루 카드로 시작한다. 일정 탭 진행 중 세션 카드에서 "진행 화면 보기" 버튼만 뺀 모양(D-day 대신 오른쪽 끝 LIVE, "N명 참여")이고, 세션이 시작돼도 맨 위 카드 모양이 바뀌지 않게 한다. 카드 없는 글자 머리로 되돌리지 않는다.
- 진행 중 경기는 내 경기·남의 경기 모두 가로 vs 카드다. 내 경기 카드에만 경기 상세와 같은 랠리 애니메이션(`RallyTeamRow`)을 넣는다.
- 다음 세션 카드에서 나를 따로 강조하지 않는다(내 아바타 앞세우기·체크 배지·"나 외 N명" 없음). 총 인원 "N명 참여 예정"만 쓴다.
- 소식 세션 카드에 '지난 회차 대비' 비교를 넣지 않는다.
- 진행 중 세션이 없으면(날짜가 아니라 진행 중 세션 유무) 다음 세션 캐러셀(과 진행 중 경기) 아래에 "소식" 섹션 피드를 둔다(`home/NewsFeed`, `GET /api/news-feed`).
  - 따로 된 지난 세션 요약 카드·'내 새 업적' 섹션은 두지 않는다. 진행 중 세션이 있으면 피드도 없다.
  - 최신 세션 카드가 위이고, 목록 끝에 다가가면 이전 세션을 이어 붙인다(무한 스크롤). `dataVersion`·당겨서 새로고침이면 보이던 목록을 둔 채 첫 페이지부터 다시 받는다.
  - 첫 로드는 스켈레톤, 첫 페이지 실패는 다시 시도, 다음 페이지 실패는 목록 끝 다시 시도다. 항목이 하나도 없으면 섹션 전체를 보이지 않는다.
  - 세션 하나가 흰 카드 하나이고, 새 회원은 세션 카드와 별개인 얇은 흰 카드로 API 순서대로 그 사이에 끼운다. 카드 사이는 20px다.
  - 피드 숫자는 모두 본문 글꼴이다(`font-num` 없음).
- 소식 세션 카드
  - 머리: 세션 이름(17 굵게)·날짜(13 흐린 글자, "11월 18일 수")·오른쪽 끝 "리포트 ›"(13 굵게 블루, 세션 리포트로). 이름이 길면 이름만 잘린다.
  - 내 칸(내가 뛴 세션만): "내 복식 평점"(평점 22·변화량 15)과 오른쪽 "랭킹"(순위 22·▲▼ 15) 두 칸. 라벨 줄·승패는 두지 않고 바탕 강조도 없다. "–"·하락·변동 없음은 일정 탭 끝난 세션 카드의 내 칸과 같다.
  - 세션 지배자: 불꽃 후광 아바타 48, 앰버 "세션 지배자" 알약, 아이디 22 굵게, "이전 → 이후" 평점 13, 오른쪽 끝 상승폭 26 초록. 경기 수·승 수는 붙이지 않는다. 누르면 그 회원 프로필이다.
  - 머리 다음 묶음(내 칸·세션 지배자·소식 줄)끼리는 구분선으로 나눈다.
- 소식 줄(API 순서 그대로)은 아바타 36 + 15 문장, 줄 최소 높이 60, 줄 사이 구분선이다. 아이디와 핵심 단어(업적 이름·"N연승"·"N위")는 검정 굵게이고 블루로 칠하지 않는다.
  - 업적: "<아이디>님이 업적 <이름>을/를 달성했어요"(을/를은 이름 끝 글자 받침), 둘째 줄 조건 13, 오른쪽 끝 받은 업적 배지 36. 누르면 그 회원 업적 전체 보기에서 그 업적으로 스크롤·강조한다.
  - 연승: "<아이디>님이 N연승 중이에요"(패배 수 없음). 누르면 그 회원 프로필이다.
  - 랭킹: "<아이디>님이 랭킹 N위 ▲k에 올랐어요"(▲k는 N위 바로 옆 작은 초록 글자, 모르면 생략). 메달·줄 끝 상승폭은 없다. 누르면 랭킹 탭으로 가고 강조·분류 변경은 하지 않는다.
- 새 회원 카드는 아바타 32, "<아이디>님이 새로 가입했어요", 오른쪽 날짜 13 흐린 글자("11월 17일", 요일·"가입" 글자 없음)다. 누르면 그 회원 프로필이다.

### 세션 참여자 시트

- 홈·일정 탭에서 참여 인원을 누르면 보기 모드로 연다. 참여자만 목록으로 보이고(아바타·아이디·게스트 라벨·'경기 중'), 체크·검색칸·하단 버튼은 없다.
- 수정은 제목 오른쪽의 글자 버튼 "수정"(블루 15px 굵게, 바탕·아이콘 없음, 제목·부제 묶음의 세로 가운데)으로 들어간다. 경기 상세 머리 '삭제'와 같은 모양에 색만 블루다.
- 수정 모드는 같은 시트 안에서 내용만 바뀐다(시트를 겹치지 않음). 제목 "참여자 수정", 하단 [취소 | 완료].
  - 완료는 저장 뒤 시트를 닫지 않고 보기 모드로 돌아간다.
  - 취소·뒤로가기는 저장 없이 보기 모드로 돌아간다.

### 일정 달력

- 달력은 달마다 6주(42칸)로 고정해 높이가 바뀌지 않는다.
- 밀면 이전·이번·다음 달 판이 함께 움직여 옆 달이 따라 들어온다. 요일 줄은 고정이고, 판은 카드 끝에서 잘린다.
- 달을 옮겨도(밀기·버튼) 고른 날은 그대로이고 아래 카드도 그 날이다. 고른 날이 보는 달 판에 없으면 블루 원은 안 보인다.
- 다른 달 날짜도 누를 수 있다. 숫자는 `pk-quiet`, 세션·기록 점은 45% 투명도이고, 누르면 그 날을 고르며 그 달로 슬라이드한다.
- 날짜 숫자에 `tabular-nums`를 쓰지 않는다(고정폭 1의 빈 자리 때문에 10~19가 원 안에서 오른쪽으로 치우쳐 보인다). 10~19 광학 보정(왼쪽 0.6px)은 고정폭을 끈 것으로 충분해 넣지 않았다.

### 탭 공통

- 탭 머리를 4탭에 통일하자고 제안하지 않는다(규칙은 `apps/web/AGENTS.md`).
- 홈 다음 세션 캐러셀과 일정 탭 날짜는 탭을 떠나도 유지하고, 선택된 탭을 다시 누를 때만 스크롤 맨 위와 함께 처음 상태로 되돌린다(`registerTabReset`). 랭킹·나 탭의 분류 선택은 되돌리지 않는다. 떠날 때 자동 초기화나 시간 경과 초기화는 하지 않는다.

### 프로필

- 프로필 머리(`ProfileHeader`)는 72px 아바타(사진·이니셜 같음) + 오른쪽 텍스트 열(이름 → 전적 → 상태메시지 줄)이고, 텍스트 열 높이가 아바타와 같다. 상태메시지는 지금 칩 모양·회원 색 그대로 텍스트 열 맨 아래에 이름 왼쪽 끝에 맞춰 두며(전적과 3px), 그 줄은 칩 높이 20px로 고정해 상태메시지가 없어도 자리를 비워 둔다. 사진·상태메시지 유무와 상관없이 머리 아래 내용 시작 위치가 같다. 이름과 전적 사이에 끼우거나 큰 말풍선으로 만들지 않는다.
- 지금 5연승 이상(`WIN_STREAK_DISPLAY_MIN`)인 회원은 랭킹 줄과 프로필 머리 아바타에 앰버(`pk-hl`) 링과 아바타 아래 끝에 걸친 가운데 태그(불꽃 + 랭킹은 숫자, 프로필은 "N연승", 앰버 바탕·잉크 글자)를 붙인다. 링은 움직이지 않고 5~9 / 10~19 / 20 이상으로 굵어지며 20 이상은 앰버 빛이 더해진다. 세션 지배자 불꽃 후광은 연승에 쓰지 않는다. 연승 여부와 상관없이 프로필 머리 높이는 같다.
- 업적 점수는 프로필 카드와 업적 전체 보기 모두 같은 점수 줄 + 게이지 바(`AchievementPointsSummary`)다.
- 업적 배지 아이콘은 24 viewBox 선 아이콘이다(`AchievementBadge`).
  - 언더독은 오른쪽을 보는 처진 귀 개 얼굴 옆모습이다. 몸 전체 옆모습·쫑긋 귀는 작게 보면 고양이·새처럼 보여 쓰지 않는다.
  - 연승 저지는 멈춤 손바닥, 환영 인사는 악수, 개근상은 로제트, 천적은 상어 지느러미다.
  - 숫자 꼬리표는 단계 업적(경기 수·승리·연승·출석 등)에만 붙이고, 연승 저지·개근상에는 붙이지 않는다(연승·출석 단계로 오해됨).
- 업적 상세 시트(나 탭·업적 전체 보기에서 업적을 누르면 뜨는 시트)는 내용 높이다. 흰 시트 머리에 96px 배지·업적 이름·조건을 둔다.
  - 받은 업적: 배지 뒤에 업적 축하 연출과 같은 앰버 빛줄기·후광을 깔고, 열 때 배지가 한 번 튀어나오고 고리가 한 번 퍼지며 빛줄기는 천천히 돈다(움직임 줄이기면 정지). 색종이·어두운 배경은 넣지 않는다. 본문은 받은 날·점수·받은 회원 수.
  - 못 받은 업적(진행 중 포함): 같은 틀에 회색 배지 + 자물쇠, 빛·움직임 없음. 본문은 진행(숫자 + 전체 폭 막대)·점수·받은 회원 수이고 "아직 못 받았어요" 줄은 없다.
  - 받은 회원은 "4명"처럼 인원수만 쓴다. 데이터는 프로필 요약과 `GET /api/achievements/holders`만 쓴다.
- 프로필 사진 확대 화면에는 사진 원만 둔다(이름·상태메시지·안내 문구·사진 바꾸기 버튼 없음). 조정 화면은 슬라이더 없이 핀치로만 조절한다.
- 삼성 인터넷(과 그것으로 설치한 PWA)의 파일 선택에 갤러리가 없는 문제는 웹으로 고칠 수 없다. 다시 고치려 하지 않는다.

## 미결

확정 전이라 코드 작업을 시작하지 않는다. 다시 꺼낼 때는 이 안들로 시안을 다시 그려 고르게 한다.

### 다른 회원이 받은 업적 보기

기록 완료·경기 상세는 정했다("경기 기록·수정"). 홈(진행 중 세션이 없을 때)은 소식 피드로 정했다("홈"). 남은 것은 홈(세션 진행 중)과 세션 상세다. 지금은 세션 진행 중 홈에 남이 받은 업적이 보이지 않고, 세션 상세에는 '내 새 업적' 카드만 있다. 나를 따로 강조하지 않고 내 업적도 같은 모양으로 둔다. 업적 줄 모양은 기록 완료·경기 상세의 `MatchAchievementRow`에 맞춘다.

- 홈(세션 진행 중) — 추천 A + C
  - A: 세션 지배자 카드 아래 '오늘 업적' 카드. 최근 3개만 보이고 전체는 세션 상세로 간다. 줄을 누르면 그 회원의 업적 상세.
  - B: 세션 머리 아래 가로로 넘기는 띠. 자리는 적게 쓰지만 이름·업적이 잘린다.
  - C: 오늘 기록 경기 줄 아래 업적 알약. 어느 경기에서 받았는지 바로 보이고, 같은 경기 줄을 쓰는 세션 상세·일정 기록에도 함께 붙는다.
  - D: 홈을 보는 중 새 업적이 생기면 하단 바 위에 4초 알림. 소란스러울 수 있어 선택 사항.
- 세션 상세(세션 리포트) — 추천 A
  - A(사람별): '이 세션 업적' 카드. 사람마다 한 줄, 받은 업적 알약을 줄 아래 나열한다. 많이 받은 사람 → 먼저 받은 사람 순. '내 새 업적' 카드는 이 카드로 합친다.
  - B(업적별): 업적마다 한 줄, 오른쪽에 받은 사람 아바타. 같은 업적을 여럿이 받은 날 보기 좋지만 누가 잘했는지는 덜 보인다.
- 데이터: 홈·세션 상세는 세션 리포트 `achievements`(참가자 전원·받은 경기·시각)로 API 변경 없이 된다.

### 홈 진행 중 세션 머리

홈 진행 중 세션 머리(세션 이름·LIVE·참여 인원)를 다음 세션 블루 카드와 같은 모양으로 맞추는 안이다.

- A(추천): 일정 탭 진행 중 세션 카드(`LiveSessionCard`)에서 버튼만 뺀 블루 카드
- B: 높이를 줄인 얇은 블루 카드
- C: 카드 없이 칩과 아바타만
