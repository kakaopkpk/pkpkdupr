# 디자인 가이드

pkpkdupr web의 화면을 바꾸거나 시안을 만들 때 따르는 결정이다. 색·버튼·경기 행·평점 표시·바텀시트·탭 머리·화면 이동 같은 규칙은 `apps/web/AGENTS.md`("현재 UX / 상태 관리 규칙"·"스타일링 규칙"·"디자인 규칙")에 있으므로 여기서 다시 쓰지 않는다. 이 문서는 그 밖의 확정된 결론과 다시 제안하지 않을 안을 모은다. 실제 값은 `apps/web/src/index.css`의 `@theme`가 기준이며 이 문서와 다르면 코드를 따른다.

## 작업 방식

- UI 변경은 구현 전에 시안부터 낸다. 디자인 캔버스에 지금 화면과 안 여러 개를 나란히 두고 고르게 한다. 시안을 만드는 순서는 `.claude/skills/design-canvas/SKILL.md`를 따른다.
- 확정 지시 전에는 코드·이슈 작업을 시작하지 않는다. 확정되지 않은 안을 기존 시안 화면에 먼저 반영하지 않는다.
- 시안은 기존 컴포넌트(`apps/web/src/components/ui/`와 해당 화면 컴포넌트)를 옮겨 그린다. 비슷한 모양을 새로 그리지 않는다.
- 아이콘·배지처럼 작게 보이는 것은 그림만 늘어놓지 말고 실제 크기로 렌더링한 화면 안에서 비교하게 한다.
- "B안으로"처럼 여러 아트보드에 걸칠 수 있는 답은 어느 아트보드인지 확인한다(예: "B안"과 "B안 + 추가 요소"가 함께 있을 때).
- 확정된 결정은 이 문서나 `apps/web/AGENTS.md`에 반영한다. 개인 메모나 캔버스에만 남기지 않는다.

시안의 기준은 지금 앱 화면과 코드다. 예전 디자인 캔버스는 참고 자료일 뿐이고(비공개라 소유자에게 공유를 받아야 열린다), 확정된 내용은 모두 이 문서와 `AGENTS.md`에 있다.

## 전체 원칙

- 검정 바탕 버튼과 코랄 계열 색은 쓰지 않는다.
- 하단 바는 아이폰풍으로 떠 있는 유리 알약 탭바와 원형 + 버튼이다. 없애지 않고, 스크롤해도 모양이 바뀌지 않는다.
- 바텀시트 위에 바텀시트를 겹쳐 쌓지 않는다.
- 코트 평면도 그림은 쓰지 않는다(기록에서 선수 자리는 중요하지 않다). 진행 중 경기의 옆에서 본 랠리 그림(바닥 선·네트·패들)은 쓴다.
- 코트 번호처럼 빈 코트도 표시하지 않는다. 추천한 코트에서 실제로 경기한다는 보장이 없다.
- 섹션 제목 위 여백은 앞 요소에서 제목 줄까지 20px, 제목 줄에서 내용까지 10px로 모든 화면이 같다(같은 섹션 안 카드 사이도 10px). 섹션 제목이 붙는 묶음은 공용 `Section`(`apps/web/src/components/ui/Section.tsx`)으로만 만든다. 화면 머리·컨트롤 바로 아래 첫 제목은 위 여백을 더하지 않고, 제목 없는 카드 사이 간격은 화면대로 둔다. 홈 "지난 세션"은 제목 바로 아래 세션 이름을 붙이는 머리라 `Section` 대신 같은 위 여백만 직접 둔다.
- 섹션 제목 옆에 목록 개수(" · N")를 붙이지 않는다. 개수 자체가 정보인 경우(홈 "추천 매칭 · 대기 N명")만 예외다.
- 화면 문구는 '선수' 대신 '플레이어', '고르기' 대신 '선택'을 쓴다. 부연 안내 문구는 넣지 않고 오류 안내만 둔다.

## 화면별 결정

### 경기 기록·수정

- 입력과 수정은 제목·버튼 문구·완료 화면까지 같은 UI다. 수정은 값이 채워져 있다는 점만 다르다.
- 저장은 길게 눌러 확정(`HoldToConfirmButton`)이다. 한 번 탭으로 바꾸지 않는다.
- 점수는 두 팀 모두 고르고 이긴 팀은 점수 비교로 정한다. 이긴 팀 점수를 11점으로 고정하거나 자동으로 채우지 않는다(듀스·대회 룰). 점수 선택은 가로 스크롤이다.
- 듀스 관련 판정·문구는 동호회 15점 캡(`docs/product.md`)을 전제로 하지만, 점수 입력 UI에는 상한을 두지 않는다.
- 세트·게임 수 개념(2선승 등)을 UI에 다시 넣지 않는다(단판만, `docs/product.md`).
- 복식/단식 선택 UI 없이 양 팀 1명씩이면 단식이다. 선수를 뺄 때 다른 선수를 자동으로 옮기지 않는다.
- 시작 시각 입력, QR(멤버 QR 추가·내 QR), 시트 바깥 X 버튼, 점수 단계 위쪽 뒤로·X 버튼, 버튼의 남은 시간 표시, 별도 빼기·선택 취소 버튼은 없다. 입력 중에 시트를 닫아도 확인 없이 닫는다.
- 플레이어 목록에서 세션 참여자를 앞에 두되 섹션·구분선으로 나누지 않는다.
- '한 판 더'는 '같은 멤버로 한 판 더'로 쓰고, 누르면 바로 진행 중 경기를 만든다. 기록 완료의 "한 판 더"/"닫기"는 같은 너비 두 칸이고 닫기가 주 버튼이다.

### 홈

- 진행 중 세션도 다음 세션과 같은 블루 카드로 시작한다. 일정 탭 진행 중 세션 카드에서 "진행 화면 보기" 버튼만 뺀 모양(D-day 대신 오른쪽 끝 LIVE, "N명 참여")이고, 세션이 시작돼도 맨 위 카드 모양이 바뀌지 않게 한다. 카드 없는 글자 머리로 되돌리지 않는다.
- 진행 중 경기는 내 경기·남의 경기 모두 가로 vs 카드다. 내 경기 카드에만 경기 상세와 같은 랠리 애니메이션(`RallyTeamRow`)을 넣는다.
- 다음 세션 카드에서 나를 따로 강조하지 않는다(내 아바타 앞세우기·체크 배지·"나 외 N명" 없음). 총 인원 "N명 참여 예정"만 쓴다.
- 지난 세션 피드에 '지난 회차 대비' 비교를 넣지 않는다.

### 탭 공통

- 탭 머리를 4탭에 통일하자고 제안하지 않는다(규칙은 `apps/web/AGENTS.md`).
- 홈 다음 세션 캐러셀과 일정 탭 날짜는 탭을 떠나도 유지하고, 선택된 탭을 다시 누를 때만 스크롤 맨 위와 함께 처음 상태로 되돌린다(`registerTabReset`). 랭킹·나 탭의 분류 선택은 되돌리지 않는다. 떠날 때 자동 초기화나 시간 경과 초기화는 하지 않는다.

### 프로필

- 프로필 머리(`ProfileHeader`)는 아바타 + 이름·전적 두 줄이고, 상태메시지는 그 아래 작은 칩이다. 이름과 전적 사이에 끼우거나 큰 말풍선으로 만들지 않는다. 머리 높이는 상태메시지 유무와 상관없이 유지한다.
- 업적 점수는 프로필 카드와 업적 전체 보기 모두 같은 점수 줄 + 게이지 바(`AchievementPointsSummary`)다.
- 프로필 사진 확대 화면에는 사진 원만 둔다(이름·상태메시지·안내 문구·사진 바꾸기 버튼 없음). 조정 화면은 슬라이더 없이 핀치로만 조절한다.
- 삼성 인터넷(과 그것으로 설치한 PWA)의 파일 선택에 갤러리가 없는 문제는 웹으로 고칠 수 없다. 다시 고치려 하지 않는다.

## 다시 제안하지 않는 것

- 기록 완료 화면의 랭킹 변동, 랭킹 화면의 반영일 문구, 승 배지
- 내 경기·랭킹 내 줄 강조용 바탕색·'나' 알약·파란 링·파란 이름
- 닫은 뒤 되돌리기 토스트, 하단 [‹ 이전] 바, 버튼이 꺼진 이유 문구, 지운 경기 목록 노출
- "파랑은 나만" 같은 색 의미 제한
- 세션 지배자 최소 경기 수·첫 세션 분리, 세션 지배자 카드 배경 불씨·테두리 불꽃(아바타 불꽃 후광만 쓴다), 달력 오늘 원 불꽃 후광
- + 버튼 광택, 새 앱 아이콘(기존 PK 로고 + 블루 배경 유지)
- 랭킹 줄 90일 추세선
- 일정 탭의 공휴일·취소 '쉼' 표시
- 평점 없음을 NR 알약·NEW 태그로 표시하기(관리자 화면 포함)

## 미결

확정 전이라 코드 작업을 시작하지 않는다. 다시 꺼낼 때는 이 안들로 시안을 다시 그려 고르게 한다.

### 다른 회원이 받은 업적 보기

지금은 남이 받은 업적이 홈에 보이지 않고, 세션 상세에는 '내 새 업적' 카드만, 기록 완료에는 기록한 사람의 업적만 보인다(남의 경기를 대신 기록하면 아무것도 안 보인다). 나를 따로 강조하지 않고 내 업적도 같은 모양으로 둔다.

- 홈(세션 진행 중) — 추천 A + C
  - A: 세션 지배자 카드 아래 '오늘 업적' 카드. 최근 3개만 보이고 전체는 세션 상세로 간다. 줄을 누르면 그 회원의 업적 상세.
  - B: 세션 머리 아래 가로로 넘기는 띠. 자리는 적게 쓰지만 이름·업적이 잘린다.
  - C: 오늘 기록 경기 줄 아래 업적 알약. 어느 경기에서 받았는지 바로 보이고, 같은 경기 줄을 쓰는 세션 상세·일정 기록에도 함께 붙는다.
  - D: 홈을 보는 중 새 업적이 생기면 하단 바 위에 4초 알림. 소란스러울 수 있어 선택 사항.
- 세션 상세(세션 리포트) — 추천 A
  - A(사람별): '이 세션 업적' 카드. 사람마다 한 줄, 받은 업적 알약을 줄 아래 나열한다. 많이 받은 사람 → 먼저 받은 사람 순. '내 새 업적' 카드는 이 카드로 합친다.
  - B(업적별): 업적마다 한 줄, 오른쪽에 받은 사람 아바타. 같은 업적을 여럿이 받은 날 보기 좋지만 누가 잘했는지는 덜 보인다.
- 기록 완료 — 추천 A
  - A: 이 경기로 참가자가 받은 업적을 모두 띠로 보인다. 축하 팝업은 지금처럼 내 업적만.
  - B: 띠는 내 것만 두고 평점 변화 줄의 아이디 옆에 작은 배지. 자리는 덜 쓰지만 눌러야 무슨 업적인지 안다.
- 경기 상세: 평점 변화 아래 '이 경기로 받은 업적' 섹션.
- 띠의 이름 표기(기록 완료 A용) — 추천 N3. 고른 표기는 홈 A 카드·경기 상세 섹션에도 맞춘다.
  - N1: 띠 맨 위에 아바타 + 아이디 한 줄. 띠가 조금 높아진다.
  - N2: 제목은 업적 이름, 둘째 줄 '<아이디>님이 받았어요'. 조건 문구는 빼고 눌러서 상세로.
  - N3: 왼쪽은 배지 대신 받은 사람 아바타, 오른쪽에 아이디와 업적 알약. 한 사람이 여러 개 받으면 알약만 늘어나고 세션 상세 A와 모양이 같다.
  - N4: 왼쪽은 지금 띠 그대로, 오른쪽 끝에 아바타와 아이디를 세로로.
- 데이터: 홈·세션 상세·기록 완료는 세션 리포트 `achievements`(참가자 전원·받은 경기·시각)로 API 변경 없이 된다. 세션 없는 경기까지 경기 상세에 보이려면 경기 상세 API에 업적을 추가해야 한다.

### 홈 진행 중 세션 머리

홈 진행 중 세션 머리(세션 이름·LIVE·참여 인원)를 다음 세션 블루 카드와 같은 모양으로 맞추는 안이다.

- A(추천): 일정 탭 진행 중 세션 카드(`LiveSessionCard`)에서 버튼만 뺀 블루 카드
- B: 높이를 줄인 얇은 블루 카드
- C: 카드 없이 칩과 아바타만
